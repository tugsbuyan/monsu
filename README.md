## 🎯 HMW (핵심 과제)
> *"어떻게 하면 우리가 몽골 유학생들이 해당 나라 언어로도 쉽게 수강신청 정보를 확인할 수 있게 할까요?"*

한국 대학의 복잡한 수강신청 시스템과 학사 용어가 낯선 **한밭대학교 신입 몽골 유학생**을 위해, 몽골어(Монгол хэл) 안내와 쉬운 한국어로 수강신청 절차를 확인하고 스스로 준비할 수 있도록 돕는 모바일 친화형 가이드 웹앱입니다.

---

## ✨ 핵심 기능 (Features)

1. **다국어(몽골어-한국어) 뷰 모드 지원**
   - **기본 모드:** 몽골어와 한국어 동시 병기로 한국어 학사 용어 습득 유도
   - **언어 토글:** `한국어 + Монгол` / `Монгол` / `한국어` 3가지 모드 자유 전환
2. **2단계 정보 제공 구조 & 학과 공식 출처 연동**
   - **1단계 (공통 신입생 가이드):** 모든 신입생 필수 4단계 절차 (수강편람 ➔ 장바구니 ➔ 본 수강신청 ➔ 수강정정)
   - **2단계 (학과별 공식 공지):** 변동 가능성이 높은 전공 안내는 컴퓨터공학과, 기계공학과 등 각 학과 공식 홈페이지 원문 링크로 즉시 연결
3. **진행 상황 모니터링 & 스마트 재조율 엔진 (Rule-based Re-scheduling)**
   - 체크리스트 실시간 진행률(%) 및 완료/남은 항목 수치 계산
   - **판단 규칙 ②:** 완료 항목 0개 시 1단계 할 일 시각적 집중 유도(Pulse 강조)
   - **판단 규칙 ④:** 마감 기한이 지난 미완료 단계 감지 시 목록 최상단 우선 재정렬 및 긴급 문의 경고 배너 표출
4. **신입생 필수 핵심 6대 용어 사전**
   - `장바구니`, `학점`, `전공필수/선택`, `교양필수/선택`, `이수구분`, `수강정정` 몽골어 대역 풀이 카드 제공
5. **발표 & 시연용 테스트 도구**
   - 하단 패널에서 `[다음 날 (+1일)]` 버튼을 눌러 마감일 경과 시 재조율 규칙을 실시간 시연 가능
   - `[초기화]` 버튼으로 언제든 초기 상태 리셋 지원

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend:** HTML5, Modern Vanilla JavaScript (ES6+), Tailwind CSS CDN, Lucide Icons
- **Storage:** Browser `localStorage` (로그인/개인정보 수집 없음)
- **Deployment:** GitHub Pages (자동 정적 호스팅)
